# 동네오븐 베이커리

## 실행

PowerShell에서 이 폴더의 `start.ps1`을 실행한 뒤 브라우저에서 http://127.0.0.1:8787 을 엽니다. Python 3 표준 라이브러리를 사용하며 별도 패키지 설치가 필요 없습니다.

```powershell
pwsh -File .\start.ps1
```

`docs/index.html`을 직접 열면 홍보 페이지와 메뉴를 볼 수 있습니다. 로그인과 글·댓글 공유를 사용하려면 사이트 서버를 실행합니다. 같은 서버에 접속한 계정은 게시판 데이터를 공유합니다. 데이터는 기본적으로 `community.sqlite3`에 저장합니다. 다른 포트나 데이터베이스 파일이 필요하면 `BAKERY_PORT`, `BAKERY_DB`를 설정합니다.

운영자 계정이 필요하면 첫 실행 전에 `BAKERY_ADMIN`과 `BAKERY_ADMIN_PASSWORD`를 환경 변수로 설정합니다. 운영자는 매장 소식 등록, 매장 표시가 붙는 댓글, 게시글 및 댓글 삭제가 가능합니다. 닉네임은 2~24자, 비밀번호는 8~128자입니다. 운영자 계정 생성 후 서버를 다시 시작해도 기존 비밀번호가 유지됩니다.

## 수업 사이트 배포

공개 주소는 https://cat9292.github.io/bakery-site/ 입니다. GitHub Pages는 main 브랜치의 docs 폴더를 게시합니다. 화면 수정은 docs에 커밋해 main으로 푸시합니다. 서버 코드와 SQLite 파일은 사이트 게시 범위 밖에 있습니다.

공개 커뮤니티는 GitHub Discussions를 사용합니다. 방문자는 공개 글을 읽고 GitHub 로그인 후 글과 댓글을 작성할 수 있습니다. 로컬 서버에서 실행하는 회원제 게시판은 별도의 실습용입니다. 기존 Render 설정은 선택 사항이며 이 수업 사이트에는 사용하지 않습니다.
