# 동네오븐 베이커리

## 실행

PowerShell에서 이 폴더의 `start.ps1`을 실행한 뒤 브라우저에서 http://127.0.0.1:8787 을 엽니다. Python 3 표준 라이브러리를 사용하며 별도 패키지 설치가 필요 없습니다.

```powershell
pwsh -File .\start.ps1
```

`public/index.html`을 직접 열면 홍보 페이지와 메뉴를 볼 수 있습니다. 로그인과 글·댓글 공유를 사용하려면 사이트 서버를 실행합니다. 같은 서버에 접속한 계정은 게시판 데이터를 공유합니다. 데이터는 기본적으로 `community.sqlite3`에 저장합니다. 다른 포트나 데이터베이스 파일이 필요하면 `BAKERY_PORT`, `BAKERY_DB`를 설정합니다.

운영자 계정이 필요하면 첫 실행 전에 `BAKERY_ADMIN`과 `BAKERY_ADMIN_PASSWORD`를 환경 변수로 설정합니다. 운영자는 매장 소식 등록, 매장 표시가 붙는 댓글, 게시글 및 댓글 삭제가 가능합니다. 닉네임은 2~24자, 비밀번호는 8~128자입니다. 운영자 계정 생성 후 서버를 다시 시작해도 기존 비밀번호가 유지됩니다.

## 공개 배포

GitHub 저장소의 루트에 이 폴더의 파일을 올린 뒤 Render에서 **New → Blueprint**로 저장소를 선택합니다. `render.yaml`은 Python 실행 환경, Waitress 서버, HTTPS 세션 쿠키와 SQLite용 1GB 영구 디스크를 설정합니다. Starter 인스턴스와 디스크에는 요금이 발생합니다. 적용 전 Render가 표시하는 비용을 확인하세요. 기존 서비스가 있다면 동일한 설정을 그 서비스에 반영합니다.

배포 후 공개 주소에서 회원가입, 게시물 작성, 댓글 등록을 확인합니다. 운영자 계정은 Render의 환경 변수로 설정합니다. DB 파일과 운영자 비밀번호는 Git에 포함하지 않습니다.

현재 상호와 메뉴는 기획안 예시입니다. 실제 매장 정보는 `public/visit.html`, 메뉴는 `public/menu.html`과 홈의 추천 메뉴에 반영합니다.

대표 빵 사진은 내장 이미지 생성 도구로 제작했습니다. 원본 프롬프트는 나무 테이블에 놓인 크루아상, 소금빵, 우유식빵을 따뜻한 아침 창빛으로 촬영한 사실적인 베이커리 사진입니다.
